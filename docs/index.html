BonXai Pruner ✂🌿

Filtros con IA para tu feed de X, con Gemini Nano dentro de Chrome. Gratis y privado.

Descargar (zip) Código en GitHub

Describís en lenguaje natural qué querés ver o no ver (“sin política”, “solo tecnología y poesía”) y la extensión evalúa cada post de x.com con el modelo Gemini Nano que ya viene en Chrome. No hay servidores, claves ni telemetría: todo ocurre en tu equipo.

Qué hace

  • Filtros por tema: “Ocultar” o “Solo mostrar”, con presets en español.
  • Sin saltos: el post se ve desenfocado mientras el modelo decide; después queda colapsado en una barra con el motivo y el botón Mostrar.
  • Feed curado: los posts que pasan tus filtros “Solo mostrar” se juntan en un panel lateral de Chrome, con búsqueda y chips por tema.
  • Ocultar posts como este y No debía ocultarse: tus correcciones se guardan como ejemplos y el modelo aprende de ellas.
  • Autores y media sin IA: listas de permitidos/bloqueados y reglas de fotos y videos.
  • Caché persistente y falla de forma segura: si el modelo no está, no se oculta nada.
  • Motor local opcional: Ollama u otro servidor compatible con OpenAI, solo en localhost.

Instalación

  1. Descargá el zip y descomprimilo (o clonalo: git clone https://github.com/ondanueve/BonXai-Pruner).
  2. En Chrome 138 o superior abrí chrome://extensions, activá el Modo de desarrollador y tocá Cargar descomprimida.
  3. Elegí la carpeta extension/.
  4. Abrí el popup de BonXai y tocá Descargar modelo si Chrome lo pide.

Requiere un equipo que soporte Gemini Nano en Chrome (ver los requisitos oficiales de la Prompt API). Si no, podés usar el motor local opcional. No está publicada en la Chrome Web Store.

English

BonXai Pruner is a free Manifest V3 Chrome extension that filters your X feed with Chrome's built-in Gemini Nano (Prompt API, Chrome 138+). Describe in plain language what to hide or show only; posts are blurred while classified, then collapsed with the reason. It has a curated feed side panel, a “Hide posts like this” button, one-click corrections used as few-shot examples, author and media rules without AI, a persistent cache, and an optional localhost engine (Ollama). No cloud, no API keys, no telemetry.

Install: download the zip, open chrome://extensions, enable Developer mode, click “Load unpacked” and pick the extension/ folder.
